# Logo sources

Fetched 2026-11-07, revised the same day. Order of preference: an SVG offered for download on the company's own press, brand or investor-relations page; otherwise the file on Wikimedia Commons; otherwise none (the site then shows a monogram).

None of the 15 official pages offered a single-logo SVG download (most offer PNG or a zip, or show the logo only as page chrome; NVIDIA's SVG is a colour-usage sheet, not a logo), so every file below is from Wikimedia Commons.

**Form.** The symbol is used where the brand has one, the wordmark only where it does not. Where the Commons file is a lockup (symbol plus wordmark), the symbol here is cut from that same file: the wordmark shapes are deleted and the `viewBox` is fitted to what is left. No shape, colour or proportion is redrawn. Where a file had no `viewBox`, one was added from its own width and height so it scales.

Every file was checked for scripts, embedded images, event handlers and external references; there are none.

Trademarks belong to their owners. Check each file page for its licence and trademark notice before reuse elsewhere.
